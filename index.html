📱 O que é o Monyze?

Monyze (Money + Analyze) é uma Progressive Web App (PWA) desenvolvida para ajudar você a gerenciar suas finanças pessoais de forma simples e eficiente, funcionando 100% offline após a instalação.

✨ Funcionalidades

  • 💾 Funciona completamente offline
  • 📊 Gráficos interativos e visuais
  • 📱 Instalável como aplicativo nativo
  • ✏️ Edição e exclusão de transações
  • 📥 Exportação de dados para CSV
  • 🌙 Modo escuro para conforto visual
  • 🏷️ Categorização automática
  • 📈 Relatórios detalhados por período

🎓 Projeto Acadêmico

Este projeto foi desenvolvido como trabalho avaliativo da disciplina Desenvolvimento híbrido de aplicativos móveis (DM122) do curso de pós-graduação.

Objetivo: Demonstrar conhecimentos em Progressive Web Apps, incluindo Service Workers, Cache API e IndexedDB.

📋 Requisitos Atendidos

  • ✅ Controle de versão (Git/GitHub)
  • ✅ Implantação em provedor (GitHub Pages)
  • ✅ HTML5 Cache API (Service Worker)
  • ✅ IndexedDB com CRUD completo
  • ✅ Funcionamento 100% offline
  • ✅ PWA instalável
